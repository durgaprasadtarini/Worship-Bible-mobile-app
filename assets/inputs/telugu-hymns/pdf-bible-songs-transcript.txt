14.
దేవుని స్తుతియించుడి - ఎల్లప్పుడు దేవుని స్తుతియించుడి ఆఆ ||దేవుని||

1.ఆయన పరిశుద్ధ ఆలయమందు - ఆయన సన్నిధిలో - ఆఆ - ఆయన సన్నిధిలో - ఎల్లప్పుడు ||దేవుని||

2.ఆయన బలమును ప్రసిద్ధిచేయు - ఆకాశవిశాలమందు = ఆఆ - ఆకాశవిశాలమందు - ఎల్లప్పుడు ||దేవుని||

3.ఆయన పరాక్రమ కార్యమునుబట్టి - ఆయన ప్రభావమును = ఆఆ - ఆయన ప్రభావమును - ఎల్లప్పుడు ||దేవుని||

4.బూరధ్వనితో ఆయనన్ స్తుతించుడి - స్వరమండలముతో = ఆఆ - స్వరమండలముతో - ఎల్లప్పుడు ||దేవుని||

5.సన్నుతంతుల సితారతోను - చక్కని స్వరములతో = ఆఆ - చక్కని స్వరములతో - ఎల్లప్పుడు ||దేవుని||

6.తంబురతోను నాట్యముతోను - తంతివాద్యములతో = ఆఆ - తంతివాద్యములతో - ఎల్లప్పుడు ||దేవుని||

7.మ్రోగు తాళములతో - ఆయనన్ స్తుతించుడి - గంభీరతాళముతో = ఆఆ - గంభీర తాళముతో - ఎల్లప్పుడు ||దేవుని||

8.సకలప్రాణులు - యెహోవాను స్తుతించుడి - హల్లెలుయామేన్ = ఆఆ - హల్లెలుయామేన్ - ఎల్లప్పుడు ||దేవుని||

15.
యెహోవాను స్తుతించుడి - ఆయన దయాళుడు - ఆయన కృప నిరంతరముండును = ఆయన కృప నిరంతర - తరముండును - ఆయన కృప నిరం - తరముండును ||యెహోవా||

1.దేవదేవునికి స్తుతులు చెల్లించుడి - ఆయన కృప నిరంతరముండును (2) ||యెహోవా||

2.ప్రభువుల ప్రభునకు స్తుతులు చెల్లించుడి - ఆయన కృప నిరంతర ముండును(2) ||యెహోవా||

3.ఆశ్చర్యకార్యములు - చేసినవాని స్తుతించుడి - ఆయన కృప నిరంతరముండును(2) ||యెహోవా||

4.ఆకాశము జ్ఞానముచే - జేసినవాని స్తుతించుడి - ఆయన కృప నిరంతరముండును(2) ||యెహోవా||

5.నీళ్ళమీద భూమిని - పరచినవాని స్తుతించుడి - ఆయన కృప నిరంతర ముండును (2) ||యెహోవా||

6.గొప్ప జ్యోతులను ని-ర్మించినవాని స్తుతించుడి - ఆయన కృప నిరంతరముండును (2) ||యెహోవా||

7.పగటినేలు సూర్యుని - చేసినవాని స్తుతించుడి - ఆయన కృప నిరంతరముండును (2) ||యెహోవా||

8.రాత్రినేలు చంద్రుని - చేసినవాని స్తుతించుడి - ఆయన కృప నిరంతరముండును (2) ||యెహోవా||

9.ఇంతవరకు సాయము - చేసిన ప్రభుని స్తుతించుడి - ఆయన కృప నిరంతరముండును (2) ||యెహోవా||

16.
స్తోత్రింతుము నీను మాదుతండ్రి - సత్యముతో ఆత్మతో నేపుడు = పరిశుద్ధాలంకారములతో - దర్శించెదము శరణం శరణం ||స్తోత్రిం||

1.శ్రేష్టయౌవుల యూటనీవే - శ్రేష్టకుమారుని యిచ్చినందున = త్రిత్వమై యేకత్వమై త్రి-లోకవాధా శరణం శరణం ||స్తోత్రిం||

2.పాపిమిత్రుడ పాపనాశక - పరమవాసా ప్రేమపూర్ణా = వ్యోమపీతుడా స్వర్ణమయుడా- పరిశుద్ధాంగుడా శరణం శరణం ||స్తోత్రిం||

3.ధవళవర్ణుడ రత్నవర్ణుడ-సత్యరూపి యనబడువాడా = నను రక్షించిన రక్షకుండా - నాధా సీవే శరణం శరణం ||స్తోత్రిం||

4.బంగరు వెంట్రుకలు తలపై - ఉంగరములుగ కనబడుచున్నవి = వేలలో నతికాంక్షనీయుడా - వేలకొలది శరణం శరణం ||స్తోత్రిం||

5.గువ్వల వంటి కన్నులు - పువ్వులవంటి చెక్కిళ్ళు = మంచి రూపము గల్గినందున - మాకు నీవే శరణం శరణం ||స్తోత్రిం||

6.చేతులు బంగారుమయము - చెక్కిన రత్నములవంటివి = కావ్యరాతిస్తంభములవలె - కన్నుడుచున్నందున శరణం ||స్తోత్రిం||

7.సంఘమునకు శిరస్సు నీవే - రాజ నీకే నమస్కారములు = ముఖ్యమైన మూలరాయి - కోట్ల కొలది శరణం శరణం ||స్తోత్రిం||

8.నీదు సేవకుల పునాది - జ్ఞానమునకు మించిన తెలివి = అందముగను కూడుకొనుచు - వేడుకొందుము శరణం శరణం ||స్తోత్రిం||

9.రాజ నీకే స్తుతిస్తోత్రములు - గీతముల మంగళధ్వనులు = శుభము శుభము శుభము నిత్యము - హల్లెలుయ ఆమేన్ ఆమేన్ ||స్తోత్రిం||

17.
సుందర రక్షకుడా - మాదు స్వతంత్రమైన దేవా = ఎల్లప్పుడు మేము - నిన్నే స్తోత్రించు - చుందు స్తుతి యిదియే - సుందర రక్షకుడా

1.రాజాధిరాజ నీవే - మా పారోనురోజా నీవే = త్వరగా వత్తుననిన - గొప్ప దేవుడా - నరుల మము జాడుమా ||సుందర||

2.వ్యాధిగ్రస్తుల వైద్యుడా - యూద గోత్రమున పుట్టితివి = ఆర్తురాలైన నాయాను విధవకు - మారుని లేపితివి ||సుందర||

3.రత్నవర్ణ వదనుడా - యూదకన్య మరియ కాత్మజా = మన్నించువాడా పరమున జేర్పువాడా - మమ్ము ప్రేమజాడుమా ||సుందర||

4.నాకము పట్టలేని - వాడా! - లోకమునకు వచ్చితివి = జీవ పానము నిచ్చి - మా దాహము తీర్చితివి - హీనునిలో నుండుమా ||సుందర||

5.మార్గం సత్యం జీవమై - మమ్ము కున్క కాపాడుచు = అరచేతిలో మమ్ము - చేక్కియున్నవాడా - మంచి గొల్లబోయడా ||సుందర||

6.ఆశ్చర్యకరుడ నీవే - మంచి ఆలోచనకర్తవు = బలుడైన దేవుండ - నిత్యుడగు తండ్రి - సమాధాన ప్రభువా ||సుందర||

7.హల్లెలుయా పాడను - మహాసత్యాత్మ వరమిహయను = ఎల్లరను జేర్ప - నుర్వికేతెంచువాడా - నిల్వక రారమ్మియా ||సుందర||

18.
యెహోవాను గానము - చేసెదము ఏకముగా - మనకు రక్షకుడాయనే - ఆయన మహిమ పాడెదము - ఆయనను వర్ణించెదము - ఆయనే దేవుడు మనకు ||యెహోవా||

1.యుద్ధశూరుడెహోవా - నా బలము నా గానము = నా పితరుల దేవుడు - ఆయన పేరు యెహోవా ||యెహోవా||

2.ఫరోరథముల సేనలను - తన శ్రేష్ఠాధిపతులను = ఎర్ర సముద్రములోన - ముంచివేసె నెహోవా ||యెహోవా||

3.నీ మహిమాతిశయమున - కోపాగ్ని రగులజేసి - చెత్తవలె దహించెదవు - నీపై లేచువారిని ||యెహోవా||

4.దోపుడు సొమ్ము పంచుకొని - ఆశ తీర్చుకొందును = నా కత్తి దూసెదను - అని శత్రువనుకొనెను ||యెహోవా||

5.వేల్పులలో నీ సమదేవుడు - పరిశుద్ధ మహానీయుడా = అద్భుతమైన పూజ్యుడా - నీ వంటివాడెవడు ||యెహోవా||

6.ఇశ్రాయేలీయులంతా - ఎంతో సురక్షితముగా = సముద్రము మధ్యను - ఆరిన నేలను నడిచిరి ||యెహోవా||

19.
ఎంత ప్రేమించెనో దేవుడు మనపై - ఎంత దయ జూపెనో = వింతగల యా దైవ ప్రేమను - స్వాంతమున ధ్యానింపరే ||ఎంత||

1.పనికిమాలిన పాపాత్ములమైన మనము ఆ - ఘనదేవునికి పిల్లల-మనబడుటకై = తన కుమారుని - మరణ - బలిరక్తమున మనలను స్వీకరించుకొనేను దీని జూడరే ||ఎంత||

2.పెంటకుప్పమీద - పడియున్న యీ నీచ - మంటి పురుగులను లేవనెత్తి = మింటిపై ఘనులతో - గూర్చుండ జేయ నీ-మంటి కేతెంచె మన వంటి దేహము దాల్చి ||ఎంత||

3.ద్రాక్షారసపు మధుర - మును మించి యా ప్రేమ - సాక్షాత్తుగా మన పయినుండగా = ఈ క్షితి నా ప్రేమ - ద్రాక్షారసముకంటె - దిక్షగ వేడి య- పేక్షింపతగునాహో ||ఎంత||

4.మనలను ప్రేమించి- తన ప్రాణమిచ్చిన-ఘనుడా కాశమునుండి మరలివచ్చి = మన దైన్యదేహమును తన - రూపముకు మార్చి - కొనిపోయి తన రాజ్య-మును మన కియును ||ఎంత||

5.గట్టిగ మనమునం-దిట్టి నిరిక్షణ - పెట్టియున్న సత్ ఐ - స్తవులు ప్రభు = వెట్టివాడో మనము - నట్టివారుగ ప్రభుని - కట్టడలను మదిని - బెట్టియుందము వేడ్క ||ఎంత||

20.
ఎంత ప్రేమ - యెంత ప్రేమ - యెంత ప్రేమయా = దేవు - డెంత గొప్ప - ప్రేమయై - వెలుంగుచుండునే ||ఎంత||

1.ఎంత లోతు - నిడివి - యెంత విరివయా - దాని = నింతయంత - యని నెంత వచించె - మనుజుడెవ్వడే ||ఎంత||

2.మనమున దల-పోయ నూహ - కందదెంతయున్ - దాని = చనువుగ జగ - మందు బొగడ మాటలందవే ||ఎంత||

3.దేవదూతలైన దానిః బాడలేరట - యింక = దేవుండే తన - సుతునొసంగి - యింత యిదియనెన్ ||ఎంత||

4.ఇంత గొప్ప - ప్రేమజూప - నూరకుండునే - వాని = చెంతజేరి సంతతంబు ప్రీతి జేసెదన్ ||ఎంత||

21.
ప్రేమా - ప్రేమా - ప్రేమా ప్రియుడవు నీవే - ఆనంద మానందమే

1.నీ ప్రేమ రుచియించిన నాడే - నన్ను నేను మరిచితినయ్యా - నీ ప్రేమధికమయ్యా - నాపై - నీ ప్రేమధికమయ్యా ||ప్రేమా||

2.పరలోక ప్రస్తరరాజా! - ప్రేమతో నేతెంచినావా - ప్రేమ తెలియగలనా? - నీ ప్రేమ - లోతు నెరుగగలనా? ||ప్రేమా||

3.దేవుని ఎన్నాళ్ళో నిన్ను - గాంచక తిరిగితినయ్యా - ప్రేమతో నా ప్రియుడ నన్ను - కౌగలించితివే ||ప్రేమా||

4.ఇహలోక సకలమహిమ - పువ్వులవలె వాడిపోవున్ - వాడదేమయ్యా నీ ప్రేమ - వాడిపోదయ్యా ||ప్రేమా||

5.నీ ప్రేమ మాధుర్యమును - వివరింప తరమౌనె నాకు - అతి సులభముగానే - పరమున - వివరించగలను ||ప్రేమా||

22.
కల్వరిలోని శ్రేష్ఠుడా - కరుణా భరిత సింహమా! = కన్ను భ్రమించు ప్రభువా! - సిలువలోని మిత్రుడా!

1.స్తుతికి పాత్రుండగువాడా - దూతలతో వేంచేయువాడా! = సుదతి మరియ పుత్రుడా! - సిలువలోని మిత్రుడా!

2.పాపులకై వచ్చినవాడా! - ప్రేమగల్గిన రక్షకుడా! - పాదములపై బడితిమి - సిలువలోని మిత్రుడా!

3.దీవెనల నిచ్చువాడా! - వసుధ కేతెంచినవాడా! = నీవే శంకరు లాప్రుడవు - సిలువలోని మిత్రుడా!

4.అయిదు రొట్టెలు మరి రెండు - చేపలతో నైదువేల = జనుల పోషించిన తండ్రి - సిలువలోని మిత్రుడా!

5.నీళ్ళను రసముగ మార్చితివి - నీళ్ళమీద నడచితివి = మెళ్ళ నొసగు మాదాత! - సిలువలోని మిత్రుడా!

6.రోగుల బాగుచేయువాడా! గ్రుడ్డికి నేత్రము లిచ్చితివి = అనాధుల నాయకుడా! - సిలువలోని మిత్రుడా!

7.హల్లెలూయా కర్తుడా! - యెల్లరు కొనియాడువాడా! = బలముతో వచ్చువాడా! - సిలువలోని మిత్రుడా!

23.
యేసు పరిశుద్ధ - నామమునకు - ఎప్పుడు అధికస్తోత్రమే

1.ఇహపరమున - మేలైన నామము - శక్తి గల్గినట్టి - నామమిది = పరిశుద్ధులు స్తుతించు నామమిది ||యేసు||

2.సైతానున్ పాతాళ - మును జయించు - వీరత్వముగల - నామమిది = జయ మొందెదము యీ నామమున ||యేసు||

3.నశించు పాపుల - రక్షించ లోక - మున కేతెంచిన - నామమిది = పర లోకమున జేర్చు నామమిది ||యేసు||

4.ఉత్తమభక్తులు - పొగడి స్తుతించు - ఉన్నత దేవుని - నామమిది = లోకమంత ప్రకాశించె నామమిది ||యేసు||

5.శోధనాగాథల - కష్టసమయాన - ఓదార్చి నడుపు - నామమిది = ఆటంకము తొలగించు నామమిది ||యేసు||

24.
1.క్రీస్తుని నామము నిత్యము నిల్పున్ - సూర్యుడున్నంత కాలము చిగురున్ ||క్రీస్తుని||

2.అతనిని బట్టి మానవులెల్లరు - తమ్మును తామే దీవించుకొనెదరు ||క్రీస్తుని||

3.అన్యజనులందరును అతని - ధన్యుడని చెప్పుకొనుచుందురు ||క్రీస్తుని||

4.దేవుడైన యెహోవా ఇశ్రాయేలు - దేవుడు స్తుతింపబడునుగాక ||క్రీస్తుని||

5.ఆయనే బహు ఆశ్చర్యకార్యములు-చేయువాడు గాన స్తోత్రార్హుండు ||క్రీస్తుని||

6.ఆయన మహిమగల నామము - నిత్యమును స్తుతింపబడునుగాక ||క్రీస్తుని||

7.సర్వభూమి ఆయన మహిమచే - నిండియుండును గాక ఆమేన్ ఆమేన్ ||క్రీస్తుని||

25.
స్తోత్రము స్తోత్రము - రక్షణ స్తోత్రము - స్తోత్రము దేవుని గొఱ్ఱెపిల్లకు = స్తోత్రము జేసెద - శ్రీయేసునకు - స్తోత్రార్హుండగు జయ విజయునకు ||స్తోత్రము స్తోత్రము||

1.దాస్యము బోయెను - యేసురక్తముచే - దాస్యము బోయి స్వ - తంత్రుడనైతిని ||స్తోత్రము జేసెద||

2.చీకటి తొలగెను - యేసు రక్తముచే - చీకటి తొలగెను - తేజము వచ్చెను ||స్తోత్రము జేసెద||

3.పాప క్షమాపణ - యేసురక్తముచే - పాపక్షమాపణ - పరమానందము ||స్తోత్రము జేసెద||

4.పాపము బాసెను - యేసురక్తముచే - పాపము బాసెను - శుద్ధుడనైతిని ||స్తోత్రము జేసెద||

5.శాపము బోయెను - యేసురక్తముచే - శాపము బోయెను - నీతియు వచ్చెను ||స్తోత్రము జేసెద||

6.సైతా నోడెను - యేసురక్తముచే - సైతా నోడెను విజయము వచ్చెను ||స్తోత్రము జేసెద||

26.
మహారాజా! యేసు! - నీకే మహిమ కలుగుగాక! = ఘనత ప్రభావములు నీవే నిత్య రాజ్యము నీదే ||మహారాజా||

1.కన్యాగర్భమున జన్మించ - సంకల్పించుకొన్నావే = పాపమెల్ల నాశము చేయ - పాపిరూపము దాల్చితివే ||మహారాజా||

2.సిలువశ్రమలను సహించి - మరణము రుచించితివే = ప్రాణము పెట్టి మము రక్షించి - తండ్రిని తృప్తిపరచితివే ||మహారాజా||

3.పాప మరణ నరకమునుండి - రక్షించ సంకల్పించి = త్రియేక దేవునితో జేర్చ - చెడుగు తీసివేసితివే ||మహారాజా||

4.పాపీ! దేవునిచే మారుమనస్సును పొందుమా = ఆత్మానుగ్రహ కాలమున వచ్చి - రక్షణ పొందుమా ||మహారాజా||

27.
కొనియాడ దరమె నిన్ను - కోమలహృదయ! - కొనియాడ దరమె నిన్ను =దనరారు దినకరు - బెనుతారలను మించు - ఘనతేజమున నొప్పు - కాంతిమంతుడ వీవు

1.ఖరుబులు సెరుపులు - మరి దూతగణములు = నురుతరంబుగ గొలువ - నొప్పు శ్రేష్ఠుండ వీవు ||కొనియాడ||

2.సర్వలోకంబుల - బర్వ దేవుడ వయ్య = నుర్వి స్త్రీ గర్భాన - నుద్భవించితివి వీవు ||కొనియాడ||

3.విశ్వమంతయు నేలు - వీరాసనుడ వయ్య = పశ్వాళితో దొట్టి - బగడియుంటివి నీవు ||కొనియాడ||

4.దోసంబులను మడియు - దాసాళి గరుణించి - యేసు పేరున జగతి - కేగుతెంచితి వీవు ||కొనియాడ||

5.నరులయందున గరుణ - ధర సమాధానంబు = చిరకాలమును మహిమ - పరగ జేయుదు వీవు ||కొనియాడ||

6.ఒ యేసు! పాన్పుగ నాయాత్మ జేకొని = శ్రేయ మొప్పగ బండు - శ్రీకర వరసుత! ||కొనియాడ||

28.
యేసునామమే పావనము - మాకు - యేసు గద నిత్య జీవనము - దాసజన - హృద్వికానమై యెల్ల - దోసములకు వినాశకరమైన ||యేసు||

1.సాధు మానసోల్లాసములు - యేసునాధుగుణ చిద్విలాసములు = బోధగొను వారి బాధ వెడలించి - మాధుర్యమగు ముక్తి - సాధనమునిచ్చు ||యేసు||

2.భక్తజన లోక పూజ్యములు - రక్తసిక్త పాద పయోజములు = ముక్తి రాజ్యాభిషిక్తుడౌ సర్వ - శక్తియుతుడైన - స్వామియగు క్రీస్తు ||యేసు||

3.దీన జన నిత్య తోషణము - సిల్వమౌని ప్రభు మృత్యు ఘోషణము = పానకము జుంటితేనియల స్వాదు - వీనులను గోలు - మానవుల కెల్ల ||యేసు||

4.పాపులకు మంచి పక్షములు - ముక్తి జాపు క్రీస్తు కటాక్షములు - పాప సంసార - కూపమునక గూలు - కాపురుష నన్ను - గాచుకొని బ్రోచు ||యేసు||

29.
యేసునామ మెంతో మధురం - క్రీస్తేసునామ - మెంతో మధురం = దోసములు మోసములు - నాశ మొనరించు ప్రభు ||యేసు||

1.స్వాంతమునను - శాంతమిడును = చింతలను భ్రాంతులను - వింతలుగ త్రుంచు ప్రభు ||యేసు||

2.నెమ్మి నిండు - కమ్మియుండు = నమ్మికలు సొమ్ములుగ - మమ్మరము జేయు ప్రభు ||యేసు||

3.ప్రేమ లెదుగ - క్షేమ మొదవు = కామగుణ పామరత - లేమి చారనీడు ప్రభు ||యేసు||

4.మోక్షదశకు - సాక్ష్య మొసగు = నక్షయ సురక్షణకు - దక్షత వహించు ప్రభు ||యేసు||

5.శీలమతుల - పాలి వేతల = తూల జన దోలి తన - జాలి కనపరచు ప్రభు ||యేసు||

6.దరిద్రులపై - దాల్మి బలువై = సారకరుణారసపు - టేరువలె బారు ప్రభు ||యేసు||

30.
వరనామమే శరణము శరణము - క్రీస్తు - వరనామమే శరణము శరణము ||వరనామమే||

1.పరమ భక్తవ్రాత - దురిత సంఘాత దుస్తరవనజాత - భీకర కీలియా క్రీస్తు ||వరనామమే||

2.సారహీనసం-సార పారావార - తారణ కారణ - తరణీయైన క్రీస్తు ||వరనామమే||

3.బేదలేముపుర - బేద నివాసుండై - యూదుల కులమున - పాదుకొన్న క్రీస్తు ||వరనామమే||

4.విత్తాదులను జాల - మత్తిల్లి జ్ఞానసం - పత్తి లేని నరకాయత్తులకును క్రీస్తు ||వరనామమే||

5.ఇలలో బాపపు మాన - వులనెల్ల మోక్షసం - కలితుల జేయగ - సిలువనొందిన క్రీస్తు ||వరనామమే||

6.పచి యున్నట్టిపి - శాచభారపుకాడి = నాచి దుఃఖించెడు - నీచులకును క్రీస్తు ||వరనామమే||

7.క్రూరమైనదేవ - తారాజిగొల్పి దు = ర్వార దుఃఖపదంబు - జేరు వారికి క్రీస్తు ||వరనామమే||

8.క్రొల్లగాను పాప - మెల్లఁ జేసి దాని = కుల్లములలో దల్ల - డిల్లువారికి క్రీస్తు ||వరనామమే||

9.కపట సేవకులకు - నుపయోగింపనిదై - నిష్పటభక్తులకెల్ల - నపవర్గమిడు క్రీస్తు ||వరనామమే||

10.ఎక్కడ జూచిన - దక్కువగ గానట్టి = చక్కని గుణముల - నిక్కమైన క్రీస్తు ||వరనామమే||

31.
యేసు నీ నామామృతము మాకెంత రుచియయ్యా = మా దోసములను హరించి మోక్షసువాసులుగ జేసుటకు - భాసుర ప్రకాశమైన ||యేసు నీ నామా||

1.వేడు కలరగ-గూడి నిను గొని-యాడువారికి = నెంతో గీడుజేసిన - పాడు వైరుల - గోడుగోడ - నంగవాని - తాడనము జేసితివి ||యేసు నీ||

2.పాపములను - హరింప నీవే - ప్రాపు మాకయ్యా = నీ దాపుజేరిన - వారికెల్లను - ఆపదలు బాపి నిత్య - కాపుగతి జూపినావు ||యేసు నీ||

3.అక్షయ కరు-ణాక్ష భువన-రక్షకా నీకే = నీ - పక్షముగ రక్షించు వారిచే - అక్షయ సుదిక్షగాను భిక్షకులమైన మాకు ||యేసు నీ||

4.అందముగ నీ - మందిరమున - పొందుగ మేము = నీ - సుందర కరుణారసమున - డెందముల యందు వెలు-గొందుటకు సుందరమైన ||యేసు నీ||

32.
మేము వెళ్ళి చూచినాము - స్వామి యేసుక్రీస్తును - ప్రేమ మ్రొక్కి వచ్చినాము - మా మనంబు లలరగ ||మేము||

1.బేదలేము పురములోన - బీదకన్య మరియకు = బేదగా సురూపు దాల్చి - వెలసె బశులపాకలో ||మేము||

2.జ్ఞానులమని గర్వపడక - దీనులమై నిత్యము = వాని ప్రేమ సకలప్రజలకు - మానక ప్రకటింతుము ||మేము||

3.తద్దర్శనమందు మాకు - బెద్దమేలు గలిగెగా = హద్దులేని పాపమంత - రద్దుపరచ బడెనుగా ||మేము||

4.మరణమెపుడో రేపోమాపో - మరియెపుడో మనమెరుగము = త్వరగా పోయి పరమగురుని - దర్శనంబు జేతము ||మేము||

5.పరిశుద్ధాత్మ జన్మ మాకు-వరముగ నొసంగెను = పరమపురము మాకు హక్కు-పరిచే దాను నిరతము ||మేము||

6.మాకు సర్వగర్వమణిగి - మంచిమార్గ మబ్బెను = మాకు నీ సువార్తజెప్ప - మక్కువెంతో గలిగెను ||మేము||

33.
రక్షకుం డుదయించినాడట - మనకొరకు బరమ - రక్షకుం డుదయించినాడట = రక్షకుం డుదయించినాడు - రారె గొల్లబోయలారా! - తక్షణమునబోయి మన నిరీక్షణ ఫలమొందుదము ||రక్షకుండు||

1.దావీదు వంశమందు - ధన్యుడు జన్మించినాడు = దేవుడగు యెహోవా మన - దిక్కుందేరి చూచినాడు ||రక్షకుండు||

2.గగనమునుండి డిగ్గి - ఘనుడు గబ్రియేలు దూత = దగినట్టు చెప్పెవారికి - మిగుల సంతోష సువార్త

3.వర్తమానము జెప్పి దూత - వైభవమున పోవుచున్నాడు = కర్తను జూచిన వెనుక - కాంతుము విశ్రమం బప్పుడు ||రక్షకుండు||

4.పశువుల తొట్టిలోన - బట్ట తోడ జుట్టబడిన = శిశువును గనుగొందు రని - శీఘ్రముగను దూత తెల్పె ||రక్షకుండు||

5.అనుచు గొల్ల లొకరి కొక - రానవాలు జెప్పుకొనుచు = ననుమతించి కడకు క్రీస్తు - నందరికిని దెల్పినారు ||రక్షకుండు||

34.
చింత లేదిక యేసు పుట్టెను - వింతగను బేత్లేహేమందున = చెంతజేరను రండి సర్వజనాంగమా! - సంతస మొందుమా ||చింత||

1.దూత తెల్పెను గొల్లలకు శుభవార్త - నా దివసంబు వింతగా = ఖ్యాతిమీరగ వారు యేసును - గాంచిరి - స్తుతు లొనరించిరి ||చింత||

2.చక్కగ గనుగొని - జ్ఞానులెంతో - మక్కువతో నా - ప్రభుని గనుగొన = చక్కగా బేత్లేము పురమున జొచ్చిరి - కానుక లిచ్చిరి ||చింత||

3.కన్యాగర్భము - నందు బుట్టెను - కరుణగల ర - క్షకుడు క్రీస్తుడు = ధన్యులగుటకు - రండి వేగమే దీనులై - సర్వమాన్యులై ||చింత||

4.పాపమెల్లను బరిహరింపను - పరమ రక్షకుడవతరించెను = దాపు జేరిన వారి కిడుక గడు భాగ్యము - మోక్షభాగ్యము ||చింత||

35.
వినరే యో నరులారా! వీనుల కింపుమీర - మనల రక్షింప క్రీస్తు - మను జావతారుడయ్యె - వినరే = అనుదినమును దేవుని తనయుని పద వనజంబులు మన మున నిడుకొనుచును ||వినరే||

1.నరరూపు దాల్చిన ఘోర - నరకుల రారమ్మని - దురితము బాపు దొడ్డ - దొరయో మరియావరపుత్రుడె = కర మరుదగు కల్వరిగిరి దరి - రయంబున ప్రభుకరుణను గనరే ||వినరే||

2.ఆనందమైన మోక్ష - మందరి కియదీక్ష - బోని తనమేని సిలువ - క్రాను కానిచి మృతిబొందెను = దీనదయాపరు - డైన మహాత్ముడ - నానబలియైన తరంగిది ||వినరే||

3.పొందుగోరినవారి - విందా పరమోపకారి - యెందరెందరి పరమా - సందపద మొందగ జేసెను = అందముననస్ దన - బొందిసురక్తము - జిందెను భక్తుల డెందము గుండగ ||వినరే||

4.ఇల మాయావాదుల మాని - యితడే సద్గురుడని - తలపోసిచూచి మతిని - శుభలభక్తిని గొలిచినవారికి = ఇలజనులకు గలుముల నలరెడు - ధనికుల సుఖములు మరియొసగును ||వినరే||

5.దురితము లణపవచ్చి - మరణమై తిరిగిలేచి - నిరతమోక్షానంద సం - దర మందిరమున కరుదుగ జనె = బిరబిర మన మందర మా కరుణా - శరనిధి చరణమే శరణని బోదము ||వినరే||

36.
ఎంతగొప్ప బొబ్బపుట్టెను - దానితో రక్షణ - మంతయును సమాప్తమాయెను = ఎంత గొప్పబొబ్బపుట్టెను - యేసునకు గల్వరిమెట్టును - సంతసముతో సిల్వక గొట్టగ - సూర్య డంధకార మాయెను ||ఎంత||

1.గలిబిలి గలిగే నొకప్పుడు - షిన్యారు బాబెలు - కట్టడమును కట్టునప్పుడు = పలుకుభాషయు నొక్కటైనను-పలువిధములగు భాషలాయెను - నలుదేసలకును - జనులు పోయిరి - కలువరిపై కలిసికొనిరి ||ఎంత||

2.పావనుండగు ప్రభువు మనకొరకై - యా సిలువమీద-చావునొందెడు సమయమందున - దేవుడా! నా దేవుడా! న-న్నేల చేయివిడిచితివి యని - యా - రావముగ మొరబెట్టెను యొ - హోవయను దన తండ్రితోను ||ఎంత||

3.అందుక దిమిరము క్రమ్ము గడియయ్యె - ఆ నీతి సూర్యుని - నంత చుట్టెను బంధకంబులు = నిందవాయువు లెన్నో వీచెను - కందు యేసుని యావరించెను - పందెముగ నొక కాటువేసెను - పాతసర్పము ప్రభువు యేసును ||ఎంత||

4.సాంతమాయె నటంచు బలుకుచును - ఆ రక్షకుడు తన - స్వంతవిలువగు ప్రాణమును విడెన్ = ఇంతలో నొక భటుడు తనదగు - నీచేతో ప్రభు ప్రక్కను బొడువగ - చెంతజేరిడి పాపులను ర - క్షించు రక్తపుధారగారెను ||ఎంత||

37.
కర్త యుదయించెను - ఒ జనులారా! - గనుగొందా మీవేళ = కర్త యుదయించె - కల్మషములు బాప - గీర్తిగలిగిన భూ-భర్త యాదిగాను ||కర్త||

1.ఘనతంతయు మాని - యాతడు చాల - వినయమును బూని = మనలను రక్షింప-జనుదెంచి నరులకై-ఘనకష్టముల బొంది-తన జీవమునిచ్చె ||కర్త||

2.ఇతర చింతలు మాని- యో జనులారా! - గతియతడేయని = సతతము మదిలోన - హితవుగ బూజించి - మతివంతులకు నెల్ల - మన్ననజేసెటి ||కర్త||

3.ఇదిగో సమయము - వేడ్కతో మన - హృదయము కానందము = సదయుడౌ క్రీస్తు భా - షణములు నెరనమ్మి - ముదముతో సేవించి-ముక్తి కనుగొండు ||కర్త||

38.
యేసుక్రీస్తుడె దేవుడొక్కడు - ఎరిగి నమ్ముడి మనుజులారా! = మోస మొందక మోక్షపతి కిక - దాసులై బ్రతుకండి రండి ||యేసు||

1.ఆకసము భూలోకములను - ఆరు దినముల లోపుగానే = ప్రాకటముగ జేసినాడు - ప్రకాశడాయన ప్రజ్ఞావంతుడు ||యేసు||

2.ఆది పురుషుని యాది స్త్రీనిక - హస్తములతో నంటి జేసెను = మేదినిన్ ఫల వనము లోపల - సాధులయి నివసింప నిచ్చెను ||యేసు||

3.వార లిద్దరు దేవునాజ్ఞను - కోరికలతో మీరినప్పుడు = గారడి పిశాచతంత్రము - వారి పరమై పాపులైరి ||యేసు||

4.వీరలందరు వారి సంతతి - వేరె లేరీ ధరణిలో దు = ష్కర్ములై దేవుని యాజ్ఞలు - మీరి రందరు నరకపాత్రులు ||యేసు||

5.ఇంత పాపభరితులై కా-సంత సత్యము లేని నరుల = నెంతగ ప్రేమించెనో దన - స్వంత ప్రాణము బలిగ బెట్టెను ||యేసు||

6.మనల పాపములన్ని బాపను - మనుజుడై మరణంబు నొంది = యెునరగ మూడవ దినమున - ఘనుడు లేచి పరము వెళ్ళెను ||యేసు||

7.ఆశతో నీ వర్తమానము - నాత్మలో నమ్మెడి వారలు = మోక్షపురికి జేరనడ్డము - వీసమైన లేదు తెలియుడు ||యేసు||

8.నమ్మకుంటే నరకమయ్యో - నెమ్మదుండదు నిజముగాను = ఇమ్మహిని నాపేక్ష విడిచి - సొమ్ము క్రీస్తుని నమ్మి బ్రతుకుడు ||యేసు||

39.
దేవుని ప్రేమ యిదిగో! - జనులారా - భావంబునఁ దెలియరే = కేవలము నమ్ముకొంటే - బరలోక జీవంబు మీకబ్బును ||దేవుని ప్రేమ||

1.సర్వలోకము మనలను - దన వాక్య - సత్యంబుతో జేసెను = సర్వోపకారుండే - మనమీద జాలిపరుడై యుండెను ||దేవుని||

2.మానవుల రక్షింపను - దేవుండు - తన కుమారుని బంపెను = మన శరీరము దాల్చెను - యా ప్రభువు - మన పాపముకు దూరుడే ||దేవుని||

3.యేసుక్రీస్తు పేరున - రక్షకుడు - వెలసినాడిలోపల = దోసకారి జనులతో - నెంతో సు - భాషలను బల్కినాడే ||దేవుని||

4.పాపభారంబుతోడ - నే ప్రొద్దు - ప్రయాసములు బొందెడి = పాపులందరు నమ్మిన విశ్రాంతి - పరిపూర్ణమిత్తునఁనెను ||దేవుని||

5.సతులైన పురుషులైనన్ యా - కర్త - సర్వజనుల యెడలను = సత్ప్రేమగ నడిచెను - పరలోక - సద్భోదలెక జేసెను ||దేవుని||

6.చావు నొందిన కొందరిన్ - యేసుండు - చక్కగ బ్రతికించెను = ఈ వసుధ బహురోగులు - ప్రభునంటియే స్వస్థతను బొందిరి ||దేవుని||

7.గాలి సంద్రపు పొంగులన్ - సద్ఘణాపి-నీళ్ళపై నడిచినాడే = మేలు గల యద్భుతముల - నీలాగు - వేలకొలదిగ చేసెను ||దేవుని||

8.చేతుల కాళ్ళలోను - రారాజు - చేర మేకుల బొందెను = పాతకులు గొట్టినారే - పరిశుద్ధ - నీతి తా మౌర్యలేకన్ ||దేవుని||

9.ఒడలు రక్తము గారగ - దెబ్బలు - చెడుగు లందరు గొట్టిరి - వడిముప్పు తలమిదను - బెట్టిరి - యోర్చెను రక్షకుండు ||దేవుని||

10.ఇన్ని బాధల బెట్టుచు - దను జంపు-చున్న పాప నరులను - మన్నించుమని తండ్రిని - యేసుండు - సన్నుతితో వేడెను ||దేవుని||

11.రక్షకుడు శ్రమబొందగా - దేశంబు - తక్షణము చీకటయ్యెన్ - రక్షకుడు మృతి నొందగ - దెర చినిగి - రాతికొండలు బగిలెను ||దేవుని||

12.రాతి సమాధిలోను - రక్షకుని - నీతిగల దేహంబును - పాతిపెట్టిరి భక్తులు - నమ్మిన - నాతులందరు జూడగ ||దేవుని||

13.మూడవ దినమందున - యేసుండు - మృతిగెల్చి లేచినాడే - నాడు నమ్మిన మనుజులు జూచిరి - నలువది దినములందున్ ||దేవుని||

14.పదునొకండుమారులు - వారలకు - ప్రత్యక్ష్యుడాయె నేసు - తుదకు పరమున కేగుచు - తన వార్త - దోడనె దెలుపుడనెను ||దేవుని||

15.నమ్మి స్నానము బొందెడి - నరులకు - రక్షణ మరి గల్గును - నమ్మనొల్లకపోయిన నరులకు - నరకంబు సిద్ధమనెను ||దేవుని||

40.
యేసునాధకథా సుధారస - మిదిగో పానము సేయరే - దోసకారి జనంబులారా - దురితభావము బాయరే ||యేసునాధ||

1.ఇహపరంబులు ఎవనిచే స్రుజి - యింపబడియెను జాడరే - యహహ! యా విభుఁడ - వతరించెను - యతని గుణములు బాడరే ||యేసునాధ||

2.దురిత-భరితుల నరక చరితుల - నరయవచ్చెను జాడరే - గురుతుగ మదినమ్మి యా ప్రభు - కరుణ మది గొనియాడరే ||యేసునాధ||

3.పనికిమాలిన వేలుపులు దేస - పరుగు లెత్తుట మానరే - తనువు మీకొరకిచ్చు క్రీస్తుని - దయకు బాత్రతఁ బూనరే ||యేసునాధ||

4.మరణబలిరక్తమున మన యం - దరిని బ్రోవను వచ్చెను - కరుణతో బాపుల బిలుచు గురు - దరికి బోవుద మిచ్చను ||యేసునాధ||

5.పరమతత్వ విధానబోధలు - బాగుగ ప్రకటించెను - చిరసుఖాస్పదపదము గోరిన - జీవులకు వినిపించెను ||యేసునాధ||

6.మరణ మొందిన కొందరికి దా - మరల ప్రాణము లిచ్చెను - వరమహాద్భుత కార్యములు ని - ద్ధర ననేక మొనర్చెను ||యేసునాధ||

7.కుటిలబుద్ధుల ద్రోసి సజ్జన - గోష్టి నుండుట గోరరే - దిటముగను నెమ్మది నిమిషమైనం - దుటకుం ద్రోసి క్రీస్తుని జేరరే ||యేసునాధ||

8.పాపములను దలంచి పశ్చా-త్తాప మెదలో బొందరే - ప్రాపు క్రీస్తుడటంచు నమ్మి య - పార సౌఖ్యము లందరే ||యేసునాధ||

9.మధురమగు సువిశేషవాక్కులు - మనసులోపల బెట్టరే - యధమ గుణములు వదిలి భక్తి ప్ర - యత్నముల తుదముట్టరే ||యేసునాధ||

41.
యేసుక్రీస్తుని గొల్వరన్న - యీ జగతిలోన - యెవ్వరు లేరు వాని కన్న - యేసుని వాక్యము - లెవ్వరి కబ్బునో - దోసము విడి పర - వాసము దొరుకును

1.సత్యుడు నిత్య డాయనన్న - యీ సర్వసృష్టి - జక్కగ సలిపి నిలిపెనన్న - వ్యత్యాసములే - మియు లేకుండిన - కృత్యము జేసెను - గూర్మితో జగమున

2.నిరాకారుడు నిశ్చయుడన్న - నరుల రక్షింప - నరావతారుడైనాడన్న - నరుల పాపములు - బరిహరించుట - కొరకై మరియకొడుకై పుట్టెను

3.పరిశుద్ధవంతు డాయనన్న - ప్రభుయేసునందు - బాపమే - గానబడుట సున్న - పరులను గావుచు - ధరలో దిరిగెను - నరుల మధ్య బహు-నిరపరాధముతో

4.భేదాభేదములు గాని బోధ - నాధుడొనరించె - సాధు - లెల్లను సంతోషింప - బాధలుబడు స - ద్రిక్తులతోడను - సాదరవాక్కులు - జక్కగ బలికెను

5.మహిలోన మనుజు లెవ్వరైన - జేయలేనట్టి - మహిమాద్భుత ములు తముల - చేసెననన్న - మహారోగులను మరి - మృతులను మ - హత్తుడు స్వస్థుల మరి గావించెను

6.వర్ణింప వలమగానివాడు - మనకొరకమయ్యో - మరణమై మరల బ్రతికినాడు - మనకోసరమయ్యో - పరలోకమునకు - మరి వేంచేసిన - వరుడగు క్రీస్తుని - పాదము బట్టుము ||యేసు||

7.పరిశుద్ధ దూతల నాదముతో - ప్రభు యేసుక్రీస్తు - ప్రకాశ వస్త్ర మహిమలతో - బరమునుండి బహు - త్వరగా వచ్చును - ధరలోనమ్మిన - నరులను బ్రోచును

8.న్యాయంబు దీర్పుదినముగలదు - నమ్మనివారెల్ల - సాయంబు వెదకి- నను గనపడదు - న్యాయము దీర్చును - నడువడి చొప్పున - నమ్మని పాపుల - నరకమునుంచును

9.నమ్మండి నష్టమునొందక - యేసుని నమ్మిన - పొమ్మని జెప్పుడు సుమ్మండి - ఇమ్ముగ గృపతో - నిలలో గాచును - పిమ్మట మోక్ష - పురమున జేర్చును

42.
పాపులయెడ క్రీస్తుని ప్రియమెట్టిదో - పరికింపరే కల్వరిగిరిపై - ఆపదలను దన కీ గతిబెట్టెడు - కాపురుషుల దెస -గనుగొనె గృపతో ||బాపుల||

1.తనప్రక్కను సిలు - వను వేసిన యొక - తస్కరు దించుక - వేడుకొనన్ - గనికరము మన - మున బెనుగొన ని-చ్చెను మోక్షము తన - తోనుండుటకున్ ||బాపుల||

2.శత్రువు లటు తను - జంపుచనుండగ - మైత్రి జూపె సమ్మతి తోడన్ - స్తోత్రము జేసెను - తండ్రీ! వీరల - దురితమెల్ల క్షమియింపవె యనుచును ||బాపుల||

3.యెరుసలేము క - న్యలు కొందరు తన - యెదుట వచ్చి - యేడ్చుచు నిలువన్ = వరుస నప్పరికి - వచ్చు నాశన గతు - లెరుంగ బలికి వా - రల నోదార్చెను ||బాపుల||

4.మితిలేని దురిత - జీవులలోపల - మించియున్న - పతితులైనన్ - హితముగ మోక్షం - బిచ్చుటకై శో - ణిత బలియిడె నా - మతికది సాక్షిగ ||బాపుల||

43.
యేసుక్రీస్తు దొరికితేను - యేమి కొదు వింకేమి భయము - దోసకారి జనులకెంతో - గాసమవు నాయేసు పేరు ||యేసు||

1.తల్లిదండ్రులకంటె చాల - దన ప్రేమ మనమీద - నెల్లకాలమందునంచు - యేసుడే మాతండ్రియౌను ||యేసు||

2.వల్లగాని వశములేని - యెల్ల మేళ్ళున్నిటి నెల్లప్పుడు - కల్లగా మన కిచ్చెడి దేవ - కొమరుడే వేరెవరు లేరు ||యేసు||

3.దండ్రియైన గండములు - మెండుగాను మముజుట్టిన - తండ్రివలె మా దరికి - వచ్చి - గండములను గదిమి బ్రోచున్ ||యేసు||

4.సత్యము మార్గము తాను - నిత్యజీవమింకా తానే = భృత్యుల కీయ మోక్షము - భువిని రక్తమంత రాల్చె ||యేసు||

5.ఎన్నరాని పాపాత్ముల - కన్నులారా కనికరించి - పున్నెమైన తన ప్రాణము - భువిని బలిపెట్టినాడు ||యేసు||

6.ఒడలు నిండ గాయములతో - నడరుచుండ మరల లేచి - వెడలి పరమందునుండి - వేడుకలు మాకంపినాడు ||యేసు||

8.ఆశతోడ దన్ను నమ్మి - యాత్మలకు దర్శనమిచ్చెడి - యేసుతో నించెవరు - సాటి - లేశమైనా లేరుసుండీ ||యేసు||

44.
యేసుక్రీస్తు సామి - నమ్మిన-దోసుల కతిప్రియుడే - దాసపులోకులు - మోక్షము జెందను - దోసములన్నిటి - మోసెను యొకనా ||దేసు||

1.జగముల కర్తయిన - దేవుని - సొగసు కుమారుండే - తగ దేవునితో విభజన - లేకను - తానేకంబై - దనరుచునుండెను ||యేసు||

2.మానవులందరికీ - గల్గిన మహాపాపము బాపన్ = మానవరూపము మహిలో దాల్చెను - మనుజుడైన పరి-శుద్ధుడై యుండెను ||యేసు||

3.నీతి ప్రకారముగ-భువిలో-నిరతము నడిచెనుగ-నాతులు బురుషులు - నా బిడ్డలనచు - ప్రీతిగ బలుకుచు - నీతిగ జూచెను ||యేసు||

4.పరమ నిర్మలముల - బోధలు-ప్రజలకు జేసెనుగ = ధర్మముదప్పక - ధాత్రిని నడిచెడి - కర్తుడు లేడని - కనుపరచెను దా ||యేసు||

5.రక్షణ బొందుటకు - నరులను-రండని బలిచెనుగ = రక్షించెను మరి - వచ్చినవారిని - దీక్షతోను శుభ-దీనమనస్సుగా ||యేసు||

6.పలుదయ్యములవల్లన్ - రోగపు-బాధలు బడుచుండ = ఖలులందరిపై - కడు దయజూపుచు - పలువిధబాధలు - బారదరిమినా ||దేసు||

7.కుంటి గుడ్డివారల్ - కుష్ఠులు కుసుమరోగులు మూగల్ = వెంటనే యా ప్రభు-యేసు సెలవుచే-వేనవేలు ధర-స్వస్థత నొందిరి ||యేసు||

8.చావుశవములెన్నో - లేపెను - జీవకరముగను = యా విధముగ - దైవత్వకార్యముల - నిలలో జేసెను - యివి గాకుండగ ||నేసు||

9.సిలువను బడినాడె - పాపపు - యిల మనుజులవల్లన్ = బలమగు పాపము-బరిహరముకై - విలువగు రక్తము - నిలలో జిందెను ||యేసు||

10.కళ్ళు నీళ్ళు కదిలెన్ - కర్తకు - గాయము లైదైనే = యెల్లలోక పా-పపుబలివేటగ - జెల్లించెను దన - శ్రేష్టపు ప్రాణము ||నేసు||

11.ఎన్నడు మనకుండే - నరకపు వేదన తాబొందెన్ = సన్నుతిగా చని - పోయెను బిమ్మట - నున్నతుడై లే - చెను మూడవనా ||దేసు||

45.
దోషభరితులమైన మాకై - యేసువా యీ జగమునన్ = నీ సుప్రాణం బిచ్చి-నావా - దోషరహిత యేసువా ||దోష||

1.కన్నై సుతుడుగ యుద్భవించిన - ఘనుడవగు పుణ్యాత్ముడా! = యెన్న లేని నీతి కృత్యము - లన్నిజేసిన యేసువా ||దోష||

2.పాపములలో మునిగినట్టి - పాపులము మా శాపము నీ = వీపు మీదను మోసినావా - పాపరహితా యేసువా ||దోష||

3.అంధకారమందు మునిగి యా - నందరహితులమైన మా = యందు ప్రీతియుంచితివి యా - నంద సహిత యేసువా ||దోష||

4.సత్యరహితులమైన మాకై - నిత్యము మా యేసువా = భృత్యుడవై యుంటివా - యిల - సత్య సహిత యేసువా ||దోష||

5.పుణ్యమగు నీ ప్రాణము నిల - ధన్యుడ బలిపెట్టి నీర - క్షణ్యమును మాకిచ్చితివి కా - రుణ్య సహిత యేసువా ||దోష||

6.మరణమైతివి స్మరణకర్త - నరులకొర కీ జగమునన్ = స్మరణజేతము నీదు నామము - మరణ రహిత యేసువా ||దోష||

7.ఖలులచే నీ కాయము నిల - ఖలులకే బలిపెట్టి నీ = ఖలులమీదను వలపు చేతను - కలుషరహితా యేసువా ||దోష||

8.నీతియగు నీనామమందున - ప్రీతియుంచెడి వారికి = ఖ్యాతి మోక్షం బివ్వవచ్చిన - దాతయగు మా యేసువా ||దోష||

9.ఖద్దున మా యాపదలకు - బద్ధుడవై నిలచి నిన్ = గుద్దువారల తప్పులన్నిటి - రద్దు పరచిన యేసువా ||దోష||

10.పరమదేవుని సుతుడవైన - పరముడా! నీ రక్తము = వరముగాను నరుల కిడితివి - ధరను బహుగా యేసువా ||దోష||

46.
యేసుక్రీస్తు ప్రభువా! - మేము నీ మోక్షము బొందుటకు = నీచపు లోకము - లోనికి వచ్చితి - నీచల బ్రోచుటకు ||యేసు||

1.పరిశుద్ధుడ వీవు - ఇలలో - పాపుల నందరిని = పరిపరివిధ కృప - వాక్కులతోడను - పిలిచితి వెల్లప్పుడు ||యేసు||

2.సత్యపు నడతలతో - జగతిని - సర్వాద్భుతములను = నిత్యము జేయుచు - నీ కృప చాల - యిలలో దెల్పితివే ||యేసు||

3.దయసహితుడ వీవు మమ్ముల - ధన్యుల జేయుటకు = బ్రియకరమగు నీ - కాయము రక్తపు - గాయము లొందితివే ||యేసు||

4.పాపుల రక్షణవే నీవిక - పరముకు దేవుడవే = పాపులగావను - ప్రాణరక్తమును - బహుగా జిందితివే ||యేసు||

5.అతి పుణ్యాత్ముడవే - క్షితిలో - వేతలను బొందితివే = మృతిని బొంది మూ-డవ దినమందున - బ్రతికియు లేచితివే ||యేసు||

6.పాపులమని దెలిసి - నీదగు - దాపున జేరగనే = పాపము బాపుచు - బ్రాపుగనుండెడి - ప్రభుడవు నీవెగదా ||యేసు||

7.దురితవిత్తిదూరా! - నమ్మిన - దురితుల స్నేహితుడా = నిరతము మమ్ముల - నీ కృప లోపల - నిలకడగా బెంచు ||యేసు||

8.నోరునింద నెదలో - నీ కృప - ప్రేరేపణ గలిగి = సారెకు వేదెద - మూర్వీకి రక్షణ - కారకుడా నిన్ను! ||యేసు||

47.
యేసు దేవం డనుటకే - సందేహమును లేదు = భాసురంబుగ దేవ సుతుడై - దోసులను రక్షింప బూనిన

1.కన్యమరియ గర్భమందున - పుణ్యనరుండై యుద్భవించుట - చెన్నుగా భూనరుల కీ మర్మంబు తెలియదుగా = మిన్నుపై ఘనదేవుడే తా-గన్న సుతుడని సాక్ష్య మివ్వగ - విన్న భక్తులు వ్రాసి దెల్పిరి-విశదముగ నీ వర్తమానము ||యేసు||

2.పరమజనకుని చిత్తమంతయు - నరులకొరకై నిర్వహించుట - కొరకు కర్తను మరణమొందిన - కరుణ గనుగొనరే = తరుణమందున నమ్మువారికి - పరమ సుఖముల నిచ్చుటకై - తిరిగి లేచి నరుడుగానే - పరమునకు నేతెంచినట్టి

3.మృత్యువును జయింప శక్తుడు - మర్త్యులచే మరణమొంద న-గత్యమని యిది నమ్ము వారికి - జాలదే తృప్తి = నిత్య మా రక్షకుని కృపా - సత్యముల దల పోయుచున్ - స్తుత్యర్పణలు జెల్లించి తుద నా - స్తుత్యమును బొందంగ వచ్చును ||యేసు||

4.పరము డేసుని మరణమును గని - గిరులు బగిలెను ధరణి వణికెను-యెరుషలేమా-లయము లోపలి-తెరయు జినిగెనుగ-మరియు సూర్యుడు చీకటాయెను-నరుడుగాడని దెలియజేయుచు-మరణ మొందినవారు కొందరు-తిరిగి లేచిరి గురుతుగాను ||యేసు||

5.నిత్యజీవము సత్యమార్గము - నేను గాకింకెవరు లేరని-భృత్యులారా చాటుడీ య-త్యంతమగు ప్రేమన్ = సత్యమని మది నమ్ము వారికి-నిత్య జీవముగలుగు దానిచే - సత్యమిదియని నమ్మకుంటె-నిత్యనరకము దప్పదనియెను ||యేసు||

48.
మా యేసుక్రీస్తుని - మరుగు గల్గెనురా = నాయాత్మా ఘనరక్ష నగము కక్కనురా ||మా యేసు||

1.ముందు నాలో బాప - ములు జాడబడెరా- డెందము తానన్ని - టిని యొప్పుకొనెరా = అందుకై బలు దుఃఖ-మాత్మ జెందెనురా - సందేహములు వీడు - జాడ గన్నొనెరా ||మా యేసు||

2.సువిశేష బోధ నా - చెవులాలించెనురా - యవివేక శాస్త్రార్థ - మంటు వీడెనురా = నవసత్క్రీస్తవగోష్ఠి - భువినాకబ్బెనురా - వివిధములగు వెల్పు - లొప్పమైరిగదరా ||మా యేసు||

3.రాగద్వేషములు సం-భ్రమమెల్ల జెడెరా - మూగిబొమ్మల పాద-మలద్రొక్కబడెరా = యోగమార్గములన్ని - యోటికుండలురా - సాగుపాపపు బుద్ధి - చతికిల్పబడెరా ||మా యేసు||

4.బాధగురువుల మోము - ల్పహలజ్జబడెరా - గాధ మంత్రములన్ని - కడగండ్లయిచెడెరా = శోధించి నాయాత్మ - శుద్ధి గోరెనురా - సాధించి ప్రభుక్రీస్తు - శరణు జొచ్చెనురా ||మా యేసు||

5.మతిలోని లోతుమ-ర్మము గానబడెరా - మితిలేని ఘనపాప-మే నిండుకొనెరా = హితముగ తన జీవ-మిచ్చె క్రీస్తుడురా - మృతిరక్తమున బాప-వితతి గొట్టెనురా ||మా యేసు||

6.కులగోత్రములబుద్ధి - కుటిలంబుదెగెరా - బలవత్పిశాచ శృం-ఖలము విరిగెనురా = సిలువ మోసినవాని - చిరసౌఖ్యోన్నతిరా - నెలవుగ నాలోన - నిలచియున్నదిరా ||మా యేసు||

7.తనపోల్కి నరుల గ-న్నానప్రేమయ్యెనురా - మనసు దేవునికి న-ర్పణ సేయబడెరా = ఘనకృపాశాంతులు - గొనెను నెమ్మదిరా - మనసు మార్పడి మోక్ష-మహిమ గన్నొనెరా ||మా యేసు||

49.
ఎంతో - శృంగారమైనది - యేసుని చరిత - మిది - యెంతో వేడ్కయున్నది-మోక్షప్రవేశము = అంతట తేజో-వంతుడు క్రీస్తుడు - చెంతనే దూత - శ్రిత జనపజ్జులు - వింతగ నుడువగ - సంతత నవ్య వ-సంతము కల్గియ - నంతజీవ రస - వంత ఫలోపవ-నాంతరములు ద-త్తాంతంబున గల- పరమపురమునకు - సంతసమున జనె - జయశబ్దముతో ||నెంతో||

1.తెరిచి - మూయంగ రానట్టి-ద్వారములారా! మీ-శిరములెత్తుకొని యుండండి-యనాదిగనుండె-వరకవాటములారా! విహరె యొ-త్తంగ బడుడీ-సురు చిరమహిము స్ఫురణలుగల మీ-దొరతన పరిష-ద్దుల కరులగు భీ-కరదురితాత్ములు-దురమున-జదిపి యు-పరిమితబల-జయ-బిరుదాంకితుడ
- చిరముగ నూతన - యెరుసలేముపుర - పరిపాలన ద-త్పురుడై యిదిగో! = నెరవుగ వచ్చెను - నిజభక్తులతో ||నెంతో||

2.సుందర - మందానిలమందు - జీవసంజీవా - నంద సౌఖ్య ప్రదమైయుండ - రేబగలంటని - మందిరవాసులప్పుడు - జయ జయ శబ్దముల = పొందుగ క్రీస్తుని - పొగడుచు బాడుచు - నందరు పరమా-నందంబున జె-న్నందితనందరి - కిందగు - రాజగ - వందనములు తగ - వరుస -నొనర్చుచు - నందముగ ప్రభు - జెందిన - భక్తుల - బృందములకు దగు - విందులోనర్చిరి - పొందిక కలిగెను - భూమికి ముక్తికి ||నెంతో||

3.వెలలేని - బంగారంపు కిరీటములు - చెలిమిన్ పరిశుద్ధవంతుల - శిరములపై బెట్టి - కళలీను ధవళ వస్త్రములు - గట్టంగ నిచ్చి - చెలువుగ మరి వా - రల చేతులలో - పల విజయార్థపు - వర్ణములొసగి స - కల దూతలు భక్తులతో గూడి - విమల పీఠము ముం - గల నిలువంబడి పొలుపుగ తమ - దేవునకును క్రీస్తుని - కెలమిని స్తోత్రము - బలఘన మనిశము = గలుగునుగాకని - బలికి నుతించిరి ||ఎంతో||

4.పరిశుద్ధవంతు లప్పుడు - శాశ్వతానంద - భరితులై వీణెలు ధరియించి - పాటలు బాడుచును - గురు రాయుడైన తమ ప్రభుని - గుణములు వర్ణించి = కరుణను మీ ర-క్తముచే మము నం-దరి ధరణింగల నరవంశస్తుల-తరములలో నుం-చరుదుగ దేవుని - కొరకుగదా మము - కొనియుంటిరి మరి- మురువుగ మిక దే-వుని సముఖంబున-దొరలును - యర్చకవరుల జేసితిరి = ధర నేలుదు మిక - సరియని మ్రొక్కిరి ||నెంతో||

50.
ఈయనా యేసు రక్షకుండు - తన - దాయ యని రక్షింప దలచెనా నన్ను = ఆయాసమగు నొక్కమొప్పు నే - మోయలేకుండ నావిపుపై నుండ - శ్రేయః కరమగు సిలువ చూపి - నాకు హాయినిచ్చెను భార - మంత వెడలించి ||ఈయనా||

1.దురితాత్ముడని త్రోయకుండ - నన్ను - పరిశుద్ధుడా యేసు - ప్రభువు కరుణింప = ధరణిలో నిది మహాద్భుతము - నే - మరతునా యా ప్రేమ మరణమోదాక! ||ఈయనా||

2.ఒపగూడని దుష్ప్రతంబుల్ - నే - దేపతేపకు జేసి - ద్వేషినై యుండ = కోపమింతైన రానీక - నన్ను - కాపురుషుడని తాను ఖండింపడాయె ||ఈయనా||

3.ఒక్క సాయంబైన లేక - బల - త్రొక్కుటల్ వడి దిటము - దొల్లి నా యెదలో = జిక్కిటకుం దానె యేతెంచి - నా - మొక్కులాలించెనే - మోదమొందగను ||ఈయనా||

4.మనస్తాపగుణము లేడబాపెన్ - ఆ - దినకరోదయమట్లు - దీప్తి మది మించెన్ = తన పాదముల జాడలబ్బెన్ - సదా - వినుతికెక్కినవాని - విమలాత్మ వెలుగున్ ||ఈయనా||

5.ఈ మహత్త్వ దెలుసుకొనగా - ద - న్నామమేసని నేడు - నాకు దృఢమయ్యెన్ = భూమిలో నా మనంబునను - ఆ - స్వామి యుపకారముల్ - సంతతము దలతున్ ||ఈయనా||

6.హతుడయ్యె నా యేసు నాకై - దు - రతి తొలగి నాకు మో - క్షము గల్గుకొరకు = అతిదయా దీర్ఘశాంతుడా - దైవ - సుతుడని యెరింగితి - శోధింపగాను ||ఈయనా||

7.దీవింపదగు నతని సిలువ - నా - జీవాంతమగుదనుక - చెలగి మ్రొక్కుచును = ఈ వసుంధర జనులకెల్ల - మీరు - సేవింపు డేసునని - చెప్పి చాటుదును ||ఈయనా||
